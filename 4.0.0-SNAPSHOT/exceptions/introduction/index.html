Exceptions

Minified throws its own exception types, so you can catch errors individually.

Checked and unchecked

Exceptions marked checked extend Exception (mostly IOException), the compiler makes you catch or declare them. Unchecked ones extend RuntimeException, catching them is optional, but it's recommended to catch all exceptions.

Subclasses are indented below their superclass, catching the superclass catches all of them.

All exceptions

Auth

minified-auth
AuthInitExceptionGets thrown when the AuthManager couldn't be initialized, for example because the base directory can't be created or the master key can't be loaded or created
LoginFailedExceptionGets thrown when the Login has failed for some Reason.
NoConnectionLoginFailedExceptionGets thrown when the Login has failed because there's no network connection The message is meant to be shown to the user, the cause is the original NoConnectionException

Java

minified-java
JavaRuntimeDownloadExceptionGets thrown when the Java runtime archive couldn't be downloaded
JavaRuntimeInstallExceptionGets thrown when a downloaded Java runtime can't be installed, for example because the archive format is unknown or there is no java executable in it
NoJavaRuntimeAvailableExceptionGets thrown when there is no Java runtime to download for the required version on this platform

Launch

minified-launch
DownloadExceptionGets thrown when there was an issue downloading anything (usually, you want to use its inheritors)
AssetDownloadExceptionGets thrown when there was an issue downloading some assets
DownloadPoolShutdownExceptionGets thrown when there was an issue shutting down the downloading pool
DownloadPoolTimeoutExceptionGets thrown when the download pool timeout was hit
FailedToInstallProfileFileExceptionGets thrown when a file of a profile couldn't be downloaded or its hash doesn't match
HttpDownloadExceptionGets thrown when there was an issue downloading something over http
LibraryDownloadExceptionGets thrown when there was an issue downloading a library or native.
NativeExtractionExceptionGets thrown when there was an issue downloading a native
FailedToCacheExceptionGets thrown when there was an issue caching something
FailedToFetchPromotionsExceptionGets thrown when there was an issue fetching the forge promotions.
FailedToFetchVersionsExceptionGets thrown when there was an issue fetching the versions
FailedToLoadLibrariesExceptionGets thrown when there was an issue loading the libraries.
FailedToLoadLoaderProfileExceptionGets thrown when the profile JSON of a mod loader couldn't be fetched or read
FailedToLoadProfileExceptionGets thrown when there was an issue loading a Profile
UnsupportedProfileFormatExceptionThe profile was saved by a newer version of minified, with a format this version can't read
FailedToReadMetadataExceptionGets thrown when there was an issue reading the neoforge metadata
FailedToRunForgeInstallerExceptionGets thrown when the forge installer couldn't be loaded or started
FailedToRunNeoforgeInstallerExceptionGets thrown when the neoforge installer couldn't be loaded or started
FailedToSaveProfileExceptionGets thrown when there was an issue saving a Profile
ForgeInstallerReportFailureExceptionGets thrown when the forge installer reported a failure
ForgePreparationExceptionGets thrown when there was an issue preparing the environment for the forge installer
LaunchFailedExceptionGets thrown when the launch failed for a reason that has no more specific exception, check the cause for details
MalformedMetadataExceptionGets thrown when the neoforge metadata is malformed
MalformedVersionJsonExceptionGets thrown when the version JSON is malformed
NeoforgeInstallerReportFailureExceptionGets thrown when the neoforge installer reported failure
NeoforgePreparationExceptionGets thrown when there was an issue preparing the environment for the neoforge installer
NoLoadersFoundExceptionGets thrown when no loaders could be found (loader exists, but no versions found)
NonZeroExitCodeExceptionGets thrown when the Game's exit code isn't zero, which most likely indicates a crash or any other issues
StopRequestedExceptionThrown at a checkpoint when the launch was stopped, Launcher.launchMinecraft catches it
UnexpectedLoaderExceptionGets thrown when an unexpected loader has been used
VersionNotFoundExceptionGets thrown when Mojang's version manifest doesn't list the requested version, or the version has no client jar to download

Modrinth

minified-modrinth
ModrinthExceptionBase runtime exception for Modrinth API failures.
ModrinthApiExceptionThrown when a request to the Modrinth API fails at the HTTP or protocol level, like when there's no connection.
ModrinthNotFoundExceptionThrown when the Modrinth API returns HTTP 404.
ModrinthRateLimitedExceptionThrown when the Modrinth API rate limits a request with HTTP 429.
ModrinthDependencyResolutionExceptionThrown when dependency resolution cannot be completed, for example by Version.download(Path) when the version has no files.
ModrinthDownloadExceptionThrown when a Modrinth file download fails or fails validation: the file has no download URL, the server answers with a non-2xx status, writing the file fails, or the file doesn't match its hash (ModrinthHashMismatchException)
ModrinthHashMismatchExceptionThrown when a downloaded Modrinth file doesn't match the hash Modrinth told us
ModrinthSerializationExceptionThrown when a Modrinth JSON payload cannot be parsed into a model.

Utils

minified-utils
ChecksumMismatchExceptionGets thrown when a downloaded file doesn't match its expected checksum, so it's corrupt or not the file that was asked for
DownloadFailedExceptionGets thrown when a file couldn't be downloaded.
DownloadInterruptedExceptionGets thrown when the downloading thread was interrupted
HttpExceptionRich HTTP exception carrying status, method, URL and a compact response snapshot.
JsonParseExceptionThrown when JSON text isn't valid
NbtFormatExceptionGets thrown when NBT data is malformed or uses something that isn't supported, your file probably is corrupt Other IOExceptions mean the file couldn't be read or written at all
NoConnectionExceptionExtended Exception for missing network connection.
OfflineModeNeedsNetworkExceptionThis exception will get thrown when the user tries to launch in offline mode, but the launcher needs network to launch for a specified OfflineModeNeedsNetworkException.Reason
StopExceptionA controlled abort/stop signal with structured details.
UnsafeArchiveEntryExceptionGets thrown when an archive contains an entry that would be extracted outside the target directory (path traversal, most likely malware)

Worlds

minified-worlds
FailedToLoadWorldExceptionGets thrown when a world or a part of a World couldn't be read from disk
InvalidWorldExceptionGets thrown when a folder isn't a Minecraft world, because it doesn't exist or has no level.dat
WorldLockedExceptionGets thrown when a world's session.lock is already taken
