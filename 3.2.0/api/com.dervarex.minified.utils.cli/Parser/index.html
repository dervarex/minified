minified-utils/com.dervarex.minified.utils.cli

Parser

classinternalSource
public class Parser

CLI Parsing Utility. Usage: 1. Create an Parser Object (with or without prefixes as argument) 2. Register your CLI arguments using Parser.register 3. Give the Parser the String[] args object that you get in your main method
